# Studio 2.1.1

- Camera fullscreen releases the portrait lock and respects system auto-rotate; closing restores portrait.
- Chamber-light switch immediately below the camera.
- Home temperature label changed to Bauraum.
- Automatic leveling defaults to off in print setup.
- More compact file-tab header, spacing and root navigation.

Includes all Studio 2.0.0 and 2.1.0 features. This is the first committed Studio source baseline; earlier releases are binary archives, not reconstructed source histories. Commits were organized by concern at publication time, without backdating.

Eight automated tests, TypeScript checks, Android release build, signature verification and emulator installation/start passed. Fullscreen rotation still needs confirmation on the user's physical phone. No print was started during checks.

Download CC-Tool-Studio-2.1.1.apk (Android 7+, ARM32/ARM64). Development-key signed with the same key as previous APKs; not a production/store signing setup. Signing keys are intentionally excluded from the repository, so independently built APKs will not necessarily update these binaries in place.

Known limits: no G-code upload, firmware updates, CC2 protocol or timelapse generation from raw frames. Videos are buffered before playback and may take time to transfer. Export saved videos before uninstalling.
