# Studio 2.1.3

- Fan commands are limited to at most one request per second.
- Intermediate drag values are coalesced; only the newest pending value is sent.
- Slider movement stays local and responsive while printer requests run.
- Every fan has an Ein/Aus control: a running fan switches to 0%, while a stopped fan switches to 100%.
- The final slider or button value is retained and sent after any request already in progress.

Download **CC-Tool-Studio-2.1.3.apk** below. Android 7+, ARM32/ARM64; version code 12. Signed with the same development key as previous Studio releases for in-place updates.
