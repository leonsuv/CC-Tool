# Studio 2.1.2

- Thick, pill-shaped fan sliders with filled tracks, without circular thumbs.
- Chamber-light switch inside the live-camera card, above the fullscreen button.
- Tap the camera preview to enter fullscreen.
- Camera image fits the viewport without scrolling or cropping, in portrait or landscape.
- Small close overlay at top left and circular light toggle at top right; light-on state uses the theme color.
- Fullscreen hides Android system bars and restores them on exit.

Nine automated tests, TypeScript checks, Android release build and APK signature verification passed. Installation, preview-to-fullscreen interaction, light controls and visual layout were checked in an Android emulator against a simulated printer. No physical print was started.

Download **CC-Tool-Studio-2.1.2.apk** below. Android 7+, ARM32/ARM64; version code 11. Signed with the same development key as previous releases for in-place updates. The matching source is tagged v2.1.2; private signing keys are not included.

SHA-256: `66b7d8f591a83e6cd88eff98ad95842604513748c1fdf21642be808c9b52cac9`

Existing limitations remain: no G-code upload, firmware updates, CC2 support or raw-frame timelapse generation. Timelapses are buffered before playback; transfer speed depends on the printer and network.
